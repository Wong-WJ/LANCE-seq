# LANCE-seq Figure 4 analysis

Code used to generate the transcriptomic analyses shown in Figure 4f–i of the LANCE-seq manuscript.

## Files

- `LANCE-seq_Figure4.ipynb` — main analysis notebook
- `figure4_utils.py` — helper functions for plotting and file output


## Input

The notebook uses the final LANCE-seq AnnData (`.h5ad`) object containing the eight liver spatial transcriptomic samples:

- Healthy: MN1, MN5, CON3
- Sham: MN3, CON1
- APAP 6 h: MN2, MN4, CON2

The input and output paths are defined in the configuration cell at the beginning of the notebook.

## Run

Open `LANCE-seq_Figure4.ipynb` in the Scanpy environment and run all cells from top to bottom.

Main dependencies:

`scanpy`, `numpy`, `pandas`, `scipy`, `matplotlib`, `seaborn`, `scikit-learn`

## Output files

The filenames below are the analysis output names. Their corresponding manuscript panels are indicated in parentheses.

- `Fig4_5A_Pseudobulk_PCA_PC1_PC2.png` — principal component analysis of the eight transcriptomic samples, showing global transcriptional relationships across experimental conditions (Fig. 4f)
- `Fig4_5B_6module_heatmap.png` — comparison of six functional transcriptional modules across Healthy, Sham, and APAP 6 h samples (Fig. 4g)
- `Fig4_6A3_MN2_MN4_expression_agreement_labeled.png` — gene-level comparison between MN2, obtained after 0 h surgery and microneedle sampling, and MN4, obtained without a prior 0 h intervention (Fig. 4h)
- `Fig4_6B3_APAP_injury_module_comparison.png` — comparison of APAP injury-related functional modules between MN2 and MN4 (Fig. 4i)

Figure 4e, which shows pairwise global gene-expression correlations among samples within the Healthy, Sham, and APAP 6 h conditions, is not generated by this notebook.

## Analysis notes

- Raw counts from spatial spots are aggregated by sample to generate sample-level pseudobulk expression profiles.
- Pseudobulk counts are converted to CPM and transformed as `log2(CPM + 1)`.
- The six functional modules used in Fig. 4g are: immediate early response, general cellular stress, inflammatory/NF-κB signaling, oxidative stress/NRF2 signaling, glutathione metabolism, and cell death/injury.
- For module scoring, each gene is z-score standardized across the eight samples, and the mean standardized expression of the available genes within each module is used as the module score.
- The MN2 versus MN4 analyses in Fig. 4h and Fig. 4i are descriptive comparisons and do not represent replicate-level differential-expression testing.
